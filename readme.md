## What I've built

### Open data and packages

- **[French-Postal-Code][repo-fpc]**: open dataset of the regions, departments, communes and postal codes of France, with one GPS point per postal code and the history of the changes, built from official INSEE, La Poste and BAN data, with automatic SQL, JSON and CSV exports. 87 stars, 19 forks, referenced on data.gouv.fr.
- **[French-Postal-Code-Package][repo-fpcp]**: Composer package for Laravel and Symfony that ships this data, with models, relations and a command to load it into your database. On [Packagist][packagist-fpc].
- **[KMark][repo-kmark]**: Markdown parser written in PHP, extending the standard syntax to attach an ID and classes to elements.
- **[pptx-enigma][repo-pptx]**: PHP tool that extracts the voice-over notes from PPTX files.

### Browser extensions

- **[job-application-tracker][repo-jat]**: keep the job offers you saw and follow each application. Everything stays in your browser. Vue, Pinia, translated in several languages including right-to-left ones, colour-blind friendly themes.
- **[devtools-resize-fix][repo-drf]**: fixes a Chromium layout bug when DevTools is docked. 166 installs in 3 months on the Chrome Web Store.

**Zairakai ecosystem**, built in the open with live coding on [Twitch][twitch], on [gitlab.com/zairakai][gitlab]:

- 7 Laravel packages (activity log, headless authentication, Twitch API, Eloquent and Blade helpers) and 6 TypeScript packages (HTTP client, i18n, accessible Vue 3 components, SCSS framework), about 20 documented public repositories.
- Production Docker images (Alpine, multi-stage, non-root) for PHP and Node.js.
- Shared quality tooling, [js-dev-tools][repo-jsdt] and [php-dev-tools][repo-phpdt]: ESLint, PHPStan, Rector, Pint, Vitest, with the automatic dependency updates, security audits and a registry of packages that must not move yet.
- A public [handbook][handbook]: code standards, Git rules and policies, also used as a RAG knowledge base.
